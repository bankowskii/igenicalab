# iGenica Lab — стратегия развития 2027–2029

Интерактивная сайт-презентация по рынку инъекционной эстетической медицины России, продуктам RecomboColl и ARTLINE, конкурентам, дистрибуции, обучению врачей, CRM и плану развития на три года.

## Публикация на GitHub Pages

Репозиторий уже содержит готовый `index.html`. Для первого включения публикации:

1. Перейти в **Settings → Pages**.
2. В разделе **Build and deployment** выбрать **Deploy from a branch**.
3. Установить **Branch: main**, **Folder: /(root)**.
4. Нажать **Save**.

Адрес будущего сайта: https://bankowskii.github.io/igenicalab/

GitHub Pages может быть не включён до выполнения этих действий. Управление Pages находится в настройках репозитория и не изменяется автоматически при загрузке HTML-файлов.

## Возможности

- адаптивная презентация для смартфона и компьютера;
- 16 разделов и навигация с отслеживанием текущего раздела;
- рыночные показатели и график;
- фильтры десяти продуктов;
- переключение целевых аудиторий;
- сценарный калькулятор годовой выручки;
- чек-лист 90 дней с локальным сохранением;
- печать / сохранение в PDF;
- первоисточники и важные оговорки по доказательствам.

## Изменение содержимого

Для простых изменений можно редактировать `index.html` непосредственно в GitHub. Внешние библиотеки JavaScript не требуются. Основной стиль и скрипты встроены в файл.
